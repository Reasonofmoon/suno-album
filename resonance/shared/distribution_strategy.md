## Phase 1: YouTube 직접 업로드 (즉시 시작)

### 비용: $0

### 채널 설정

- **채널명**: Music of Moon (또는 기존 채널명 유지)
- **프로필**: 통일된 브랜딩 (brand_guide.md 참조)
- **AI 콘텐츠 공시**: 업로드 시 "AI 생성 콘텐츠" 레이블 설정

### 콘텐츠 전략

| 유형 | 길이 | 목적 | 빈도 |
| --- | --- | --- | --- |
| 롱폼 앨범 | 2-8시간 | Watch Time + Premium 수익 | 주 1회 |
| 비주얼라이저 | 3-5분 | 검색 유입 + 개별곡 노출 | 주 2-3곡 |
| Shorts | 30-60초 | 알고리즘 유입 + 구독 유도 | 주 3-5개 |

### 수익화 조건 (YPP)

| 요건 | 현재 | 필요 |
| --- | --- | --- |
| 구독자 | ⬜ 확인 필요 | 1,000명 |
| Watch Time | ⬜ 확인 필요 | 4,000시간 (12개월) |
| Shorts 조회수 | ⬜ 대안 경로 | 1,000만회 (90일) |

> 💡 **롱폼 배경음악은 Watch Time 누적에 가장 유리**
> 3시간 영상 1개 = 일반 10분 영상 18개 분량

### Phase 1 핵심 지표

- 월 업로드: 앨범 4개 + Shorts 15개
- 목표: 3개월 내 YPP 조건 달성
- 추적: 조회수, Watch Time, 구독자 증가율

## Phase 2: DistroKid 전환 (구독자 500+ 또는 월 $50+ 시)

### 전환 이유

1. **OAC 획득** → 음표 마크, 앨범 섹션, 검색 우선
2. **멀티 플랫폼** → Spotify/Apple Music 추가 수익
3. **Content ID** → 무단 사용 수익 보호
4. **Topic 채널 병합** → 구독자 통합

### 추천 플랜: DistroKid Musician ($22.99/년)

- 무제한 업로드
- AI 음악 허용 (검증된 Suno 성공 사례 다수)
- Content ID: 필요 시 추가 ($4.95/싱글)

### DistroKid AI 업로드 규칙

1. Suno **유료 플랜 필수** (상업적 권리)
2. 아티스트명 = 본인 크레딧 (AI 도구가 아닌 크리에이터로)
3. 특정 아티스트 모방 금지
4. 스팸 대량 생성 금지
5. AI disclosure 체크박스 필수

### OAC 신청 프로세스

1. DistroKid로 첫 싱글 발매 → YouTube Music 배포
2. "Music of Moon - Topic" 채널 자동 생성 확인
3. DistroKid 대시보드 → OAC 신청
4. 기존 채널 + Topic 채널 병합
5. 심사: 2-6주

### Content ID 주의사항

- 유통 트랙과 본채널 롱폼 영상 트랙을 **별도 관리**
- 같은 곡 사용 시 자기 Content ID 충돌 가능
