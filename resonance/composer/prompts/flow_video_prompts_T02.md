# T02 Comfortable Melancholy — Flow Loop Prompts (20)

> Goal: beautiful, low-distraction visual loops for Suno long-form album videos.
> Generation mode: `Flow -> Frames to Video` with the same image as first and last frame.
> Theme aesthetic: neon-lit nostalgia, midnight blue tones, purple accents, soft ambient glow.

## Global Flow Settings

- Duration per clip: `8s`
- Aspect ratio: `16:9`
- Camera: `locked tripod`
- Motion amount: `very subtle`
- Prompt language: `English`
- Negative suffix (append to every prompt):
  - `no cuts, no scene change, no camera shake, no sudden motion, no text, no watermark, no logo, no human face close-up`
