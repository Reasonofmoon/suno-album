# composer_theme_cafe_jazz

## Scope

- Theme ID: T01
- Theme Name: Cafe Jazz
- Audience Intent: 카페 배경음악, 공부, 작업, 독서, 브런치 분위기
- Target Runtime: 2h 30m (15 tracks × 10min avg)
- Target BPM Range: 80-110

## Reference Keyword Set

- Primary: cafe jazz, coffee shop jazz, smooth jazz, bossa nova, jazz piano
- Secondary: rainy day jazz, afternoon jazz, cozy cafe, warm instrumental
- Long-tail: 3 hour cafe jazz playlist, background jazz for studying, coffee shop ambience music

## Energy Curve Plan

1. Opening (0-20%): 비 오는 아침 카페 — 조용한 피아노 솔로, 부드러운 브러시 드럼, 미니멀
2. Build (20-45%): 점심 브런치 — 기타 듀오 추가, 약간의 보사노바, 리듬감 상승
3. Peak (45-65%): 오후 피크 — 트럼펫/색소폰 등장, 풀 콤보, 리치한 하모니
4. Sustain (65-90%): 늦은 오후 — 비브라폰, 클라리넷, 로즈 피아노, 따뜻한 유지
5. Fade (90-100%): 저녁 마감 — 솔로 피아노 복귀, 템포 감소, 부드러운 마무리
