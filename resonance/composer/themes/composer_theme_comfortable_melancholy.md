# composer_theme_comfortable_melancholy

## Scope

- Theme ID: T02
- Theme Name: Comfortable Melancholy
- Audience Intent: 감성 야간 작업, 새벽 독서, 비 오는 밤 감상, introspective 시간
- Target Runtime: 2h 30m (15 tracks × 10min avg)
- Target BPM Range: 65-95

## Concept Statement

> **"아름다운 슬픔"** — 2026년 최대 트렌드인 '무드 기반 리스닝'의 핵심.
> 장르가 아닌 감정으로 듣는 음악. 따뜻한 우울함, 편안한 그리움.
> Chillgressive + Ambient + Lo-fi + Trip-hop + 80s Synth Revival의 경계를 넘나드는 융합.

## Reference Keyword Set

- Primary: comfortable melancholy, emotional ambient, chill study music, late night music
- Secondary: aesthetic lofi, dreamy synth, nostalgic piano, midnight ambient, emotional electronic
- Long-tail: 3 hour late night study playlist, melancholic ambient music for reading, emotional piano and synth mix

## Energy Curve Plan

1. Opening (0-20%): 자정의 방 — 미니멀 피아노 + 아날로그 신스 패드, 빗소리 레이어
2. Build (20-45%): 기억의 복도 — Lo-fi 비트 도입, 일렉트릭 기타 리버브, Rhodes
3. Peak (45-65%): 감정의 정점 — Chillgressive 비트 + 현악 앙상블, 깊은 일렉트로닉
4. Sustain (65-90%): 수용과 평온 — Trip-hop 리듬, 첼로 솔로, 무그 신스
5. Fade (90-100%): 새벽의 빛 — 솔로 피아노 복귀, 공간이 넓어지는 앰비언트
