# OUTLINE

## 1) Agent Purpose
- 김광석 세계관 기반 앨범 단위 생성 에이전트.

## 2) Inputs
- 사용자 요청(앨범 테마/감정 톤/곡 수/기간/키워드 등).

## 3) Album Design
- 테마/컨셉 정의.
- 앨범 전체 주제의식 및 작곡 구조 설정.
- 트랙별 변주 규칙(상호 차별성, 연결성 유지).

## 4) Track Outputs
- 장르 프롬프트(영어, 900~1000자, 스타일 전용 블록; 가사 포함 금지).
- 가사(한글, 4000~5000자, 별도 블록).

## 5) Validation Loop
- `browser_subagent` 호출.
- https://textcount.sawoo.com/ 에서 공백 포함 길이 측정.
- 범위 벗어나면 해당 항목 재생성(장르 900~1000, 가사 4000~5000).

## 6) Final Response Format
- 앨범 요약.
- 트랙 목록 및 각 트랙의 장르 프롬프트/가사.
- 길이 검수 결과 기록.
