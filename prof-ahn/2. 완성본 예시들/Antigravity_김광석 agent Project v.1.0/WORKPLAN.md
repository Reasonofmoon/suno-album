# WORKPLAN

## Project
앨범 단위 김광석 에이전트 워크플로우/프롬프트 설계 및 검수 절차 통합.

## Steps
1) `김광석 에이전트 map.MD`와 `universal_browser_control.md` 구조/형식을 확인한다.
2) 앨범 설계 규칙(테마/컨셉/주제의식/작곡 구조/트랙 변주)을 정의한다.
3) 길이 검수 루프(장르 프롬프트 900~1000자, 가사 4000~5000자, 공백포함)와 `browser_subagent` 호출 절차를 워크플로우에 통합한다.
4) 최종 에이전트 프롬프트(또는 문서 업데이트) 작성 후 형식 검증 체크리스트를 정리한다.

## Acceptance
- 앨범 단위 결과물이 김광석 세계관과 일관된다.
- 트랙들이 앨범 테마로 연결되면서도 상호 차별성을 갖는다.
- 길이 검수 규칙과 재생성 조건이 명확히 문서화된다.
- 실행 모델: Gemini 3.0 Pro 명시.
