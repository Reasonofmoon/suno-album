PKM-Centric Curriculum Obsidian + Claude Code + Antigravity CLI Personal Knowledge Operating System

노트가 창작의 엔진이 되는 방법

이 페이지는 옵시디언 마크다운 노트에 맥락을 구조화하고, 이를 CLI 기반 AI 창작 루프와 연결해 실제 콘텐츠/코드/디자인 산출물을 만드는 교육 커리큘럼을 소개합니다. 핵심은 더 많은 프롬프트가 아니라, 더 정확한 맥락 운영입니다.

Step 1. Curriculum Plan

기획 핵심

  • 문서 자산(노트)을 실행 자산(CLI)으로 연결하는 운영법을 학습
  • 단발성 결과물이 아니라 반복 가능한 창작 파이프라인 구축
  • 학습자는 매 모듈마다 노트 템플릿 + 실습 결과물을 남김
Outcome: 재현 가능한 개인 창작 시스템
Step 2. Design Directives

디자인 지침

  • 테마: Editorial Terminal (정제된 기술 문서 감성)
  • 강한 타이포 대비: Display Sans + Reading Serif + Mono 메타
  • 비대칭 정보 배치, 카드별 역할 분리, 트랙 필터 인터랙션
  • 접근성: WCAG AA 대비와 키보드 포커스 우선
Style: Bold hierarchy, low-genericity
Step 3. HTML Implementation

8-Module Curriculum

학습 트랙 필터를 눌러 모듈의 초점을 바꿔보세요.

01. PKM 구조와 노트 정보 모델

Vault 구조, 노트 타입, 링크 정책을 설계해 맥락 손실을 줄입니다.

02. Context Kernel 작성법

문제, 독자, 제약, 스타일, 검증 기준을 한 노트에 정규화합니다.

03. CLI 루프 기본기

Claude Code/Antigravity CLI에서 초안 생성 -> 수정 -> 검증의 기본 루프를 익힙니다.

04. 프롬프트 자산화

프롬프트를 일회성 채팅이 아닌 재사용 가능한 노트 자산으로 관리합니다.

05. 품질 검증 파이프라인

사실성, 일관성, 톤, 근거를 체크하는 검증용 프롬프트 체인을 구축합니다.

06. 멀티 워크플로우 조합

리서치/작성/리뷰 워크플로우를 상황별로 엮어 생산성을 올립니다.

07. 발행 포맷 전개

블로그, 문서, 발표자료 형태로 동일 맥락을 전개하는 방법을 다룹니다.

08. 회고와 장기 축적

반복 실험 로그를 남겨 개인 지식 운영체계를 장기적으로 고도화합니다.

Studio Protocol

실전 운영 규칙

  • 모든 세션은 `Context Kernel` 노트 갱신으로 시작
  • CLI 실행 전 "목표/독자/제약/검증기준" 4요소 확인
  • 산출물은 "유지/수정/삭제" 3분류 회고로 축적
  • 매주 1회, 반복 오류를 템플릿 규칙으로 승격
