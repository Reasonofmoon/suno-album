# PKM x AI 창작 커리큘럼 웹사이트 기획

## 1) 기획: 웹사이트 목표와 커리큘럼 구조

### 프로젝트 목표
- 개인 지식관리(PKM) 노트를 AI 창작의 운영체계로 쓰는 방법을 설명한다.
- 옵시디언 마크다운 노트 -> CLI 실행 -> 산출물 검증까지의 루프를 커리큘럼으로 제공한다.
- 초심자도 즉시 시작할 수 있는 실습 중심 구조를 제공한다.

### 핵심 가치 제안
- "툴 사용법"이 아니라 "맥락 운영법"을 가르친다.
- 지식(노트), 실행(CLI), 결과물(콘텐츠/코드/디자인)을 하나의 루프로 연결한다.
- 재사용 가능한 노트 템플릿과 주차별 실습 시나리오를 동시에 제공한다.

### 대상 사용자
- 개인 창작자, 1인 개발자, 콘텐츠 제작자
- 옵시디언과 CLI를 같이 쓰고 싶지만 흐름이 정리되지 않은 사용자

### 콘텐츠 아키텍처
- Hero: 문제 정의 + 한 줄 가치
- Why PKM Loop: 노트 중심 창작 루프 설명
- Curriculum Grid: 8개 모듈
- Studio Protocol: 실전 운영 규칙
- Design Guidelines: 사이트 시각/콘텐츠 지침 공개
- Starter Kit: 맥락 노트 템플릿 및 시작 절차

### 8개 모듈 커리큘럼
1. PKM 운영 원리와 폴더 구조
2. 맥락 노트 설계(문제, 독자, 톤, 제약)
3. Claude Code/Antigravity CLI 기본 루프
4. 프롬프트를 노트 자산으로 관리하는 법
5. 산출물 검증(사실성, 스타일, 재현성)
6. 멀티 에이전트/워크플로우 조합 전략
7. 발행 파이프라인(블로그, 문서, 발표자료)
8. 회고 자동화 및 장기 지식 축적

## 2) 세부 디자인 지침

### 비주얼 방향
- 테마: "Editorial Terminal"
- 인상: 차갑지만 정제된 실험실 + 고급 편집 디자인
- 원칙: 강한 타이포 대비, 선명한 정보 계층, 거친 질감의 배경

### 타이포그래피
- Display: `Bricolage Grotesque` (강한 헤드라인)
- Reading: `Source Serif 4` (긴 문장 가독성)
- Meta/Code: `IBM Plex Mono` (CLI/노트 맥락)
- 크기 대비를 크게 둬서 시선 이동을 명확히 만든다.

### 컬러 시스템
- 베이스: 거의 검정에 가까운 청회색
- 포인트1: 산성 라임(활성 상태, CTA)
- 포인트2: 차가운 청록(구조 요소)
- 포인트3: 따뜻한 코랄(주의/핵심 강조)
- 모든 색은 CSS 변수로 관리한다.

### 레이아웃 규칙
- 데스크톱: 비대칭 12컬럼 느낌의 2단 구조
- 모바일: 단일 컬럼, 콘텐츠 순서 유지
- 카드 간 간격/내부 패딩은 8px 계열 스케일 준수

### 상호작용
- 섹션 진입 시 페이드+슬라이드 등장
- 모듈 필터 버튼으로 학습 트랙만 강조
- 카드 hover 시 미세한 기울기와 하이라이트

### 접근성
- 명도 대비 WCAG AA 이상 유지
- 키보드 포커스 링 명확히 표시
- 과한 애니메이션은 `prefers-reduced-motion` 대응

## 3) 구현 범위
- 단일 정적 HTML(`index.html`)로 구현
- 외부 빌드 도구 없이 즉시 실행 가능
- 실제 수업 소개 페이지로 바로 전환 가능한 수준의 콘텐츠 포함
