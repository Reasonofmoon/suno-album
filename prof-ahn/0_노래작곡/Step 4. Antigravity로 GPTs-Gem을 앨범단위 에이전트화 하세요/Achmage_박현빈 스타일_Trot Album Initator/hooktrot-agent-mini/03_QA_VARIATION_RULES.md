# 03_QA_VARIATION_RULES.md

## 목적
이 문서는 “고반복 훅송 네오-트로트(댄스 트로트) 앨범”을 여러 트랙으로 생성할 때,
1) 매 트랙이 훅-중독성-찰짐을 유지하면서도,
2) 앨범 단위로는 서로 다른 베리에이션(키/리프/메타포/라임/구호/섹션 운용)을 확보하고,
3) SUNO 출력에서 흔히 발생하는 “EDM 드리프트(트로트 성분 소실)”, “인트로 과장(빌드업 과다)”, “영어 번역 가사 혼입”, “가사 번역체/딱딱함”을 QA 단계에서 잡아내고 수정하는
운영 규칙과 검수 기준을 제공한다.

이 문서는 생성 파이프라인의 마지막 관문이다. 생성 결과물은 반드시 본 문서의 QA를 통과해야 한다.

## [V] Variation Core: 변형 가능한 것과 불변 DNA

### [V-LAW 0] 불변 DNA (Album Invariants)
아래 항목은 트랙이 바뀌어도 절대 훼손하지 않는다.

1) 장르 정체성  
네오-트로트 / 댄스 트로트 / 디스코-고고 기반. “클럽 EDM” 단독으로 들리면 실패다.

2) 그루브 핵  
4/4, 포 온 더 플로어 킥은 고정. 단, 트로트 셔플 오버레이(미세한 스윙 감각)는 항상 존재해야 한다.

3) 훅 설계  
2~3음절 반복 훅을 중심으로, 콜 앤 리스폰스(구호 트리거)를 훅 빈칸에 설계한다.

4) 가사 질감(찰짐)  
자음 타격(ㅂ/ㄷ/ㄱ/ㅆ 계열), 동사 반복(“X한다 X해”), 끝소리 라임(종결 음절의 맞물림), 짧은 관용구/과장 비유를 유지한다.

5) 섹션 대비(밀도 대비)  
Verse는 말맛/리듬 전달 중심으로 미니멀, Chorus는 훅과 합창으로 풀스택. 대비가 약하면 실패다.

6) 인트로 제약  
훅 리프가 곡 시작 2마디 이내에 등장. 인트로는 최대 4마디. 빌드업을 길게 끌면 실패다.

7) 언어 규칙  
기본은 한국어 가사. 영어 문장 금지. 허용되는 외래어/구호는 단어 1개 수준의 초단발(예: Hot, Hey)로 제한하며, 옵션으로 “핫/헤이”처럼 한글 표기로 대체 가능해야 한다.


### [V-LAW 1] 트랙별 변형 허용 범위 (Track Variation Budget)
각 트랙은 아래 항목에서만 변형을 허용한다. 변형은 1곡당 3~5개 축만 선택한다. 모든 축을 동시에 바꾸면 정체성이 흐려진다.

1) 템포  
권장 136~144 BPM. 기본값 140.  
136~138은 “조금 더 트롯”, 142~144는 “조금 더 행사/댄스”로 이동한다.

2) 키(조성)  
권장 단조: F# minor, E minor, G minor, C# minor, D minor.  
한 앨범에서 같은 키 반복은 최대 2곡까지.

3) 훅 핵심 음절쌍(2~3음절 반복 코어)  
예: 화끈/후끈/뜨끈/따끈/번쩍/반짝/심쿵/쿵쾅/찐득/끈적/딱/찰칵  
한 앨범에서 동일 코어 훅은 1회만 사용.

4) 메타포(의미장)  
불/열/노을/엔진/네온/불꽃, 또는 얼음/전기/스파크/자석/폭죽, 또는 술/입술/달달/꿀, 또는 스포츠/질주/골인 등.  
단, “사랑 앞에 정신/이성 무너짐 + 몸 반응”이라는 핵심 정서는 유지한다.

5) 라임 페어(끝소리 라임)  
매 트랙 Verse에서 최소 2쌍 이상의 라임 페어를 새로 만든다.  
같은 라임 페어를 앨범에서 재사용하지 않는다.

6) 리프 주역 악기 비중  
브라스 중심, 또는 브라스+아코디언 강조, 또는 기타 고고 칩 강조.  
단, 브라스 콜앤리스폰스 역할은 완전히 사라지면 안 된다.

7) 댄스 브레이크 구호 문장 세트  
오른쪽/왼쪽/한 바퀴/손뼉/점프/박수 등 지시 구호는 매 트랙 새로 구성한다.


### [V-LAW 2] “EDM 드리프트 방지” 최소 트로트 표식 (Trot Markers)
아래 표식 중 최소 5개가 한 곡에 명확히 존재해야 한다. 4개 이하면 EDM으로 기운다.

1) 고고 베이스(옥타브 바운스 + 오프비트 5도/8도 팝)  
2) 팔뮤트 기타 ‘궁짝’  
3) 브라스 리프가 메인 멜로디를 리드  
4) 콜 앤 리스폰스(보컬 문장 끝에 악기 답가 또는 구호)  
5) 벌스에서 말하듯 리드미컬한 트로트 프레이징  
6) 훅에서 고음 벨트 + 짧은 꺾기 + 깨끗한 비브라토  
7) 펜타토닉 중심 멜로디 감각(과한 EDM 음계 진행 금지)  
8) 8마디 전환마다 탐/필/심벌로 마디 경계가 선명함

## [Q] QA Core: 품질 게이트, 점수화, 통과 기준

### [Q-LAW 0] QA는 “형태 검사 → 기능 검사 → 중독성 검사 → 다양성 검사” 순서로 한다
1) 형태 검사: 섹션 구성, 길이, 언어 규칙 위반 확인  
2) 기능 검사: 훅 타이밍, 밀도 대비, 트로트 표식 확인  
3) 중독성 검사: 훅의 반복률, 발음 난이도, 라임/자음 타격  
4) 다양성 검사: 앨범 내 중복 여부(훅/라임/메타포/구호)

### [Q-Score] 6축 점수표 (0~5점, 총 30점)
각 축은 0~5점으로 평가한다. 총점 24점 이상, 그리고 필수 축 최소점 조건을 만족하면 통과다.

1) Hook Adhesion (필수)  
기준: 훅이 2마디 이내 제시, 코러스가 0:12 전후로 진입, 훅이 단순하고 따라부르기 쉬움  
최소 통과: 4점

2) Chajjim Index (필수)  
기준: 2~3음절 반복 훅, 동사 반복(한다 해), 자음 타격, 끝소리 라임이 충분함  
최소 통과: 4점

3) Trot Identity (필수)  
기준: 트로트 표식 5개 이상, EDM 드리프트 없음, ‘행사/합창’ 감각 존재  
최소 통과: 4점

4) Section Contrast  
기준: Verse 미니멀, Chorus 풀스택, Pre는 빌드, Dance break는 퍼포먼스 구간이 분리됨  
최소 통과: 3점

5) Lyric Naturalness  
기준: 번역체 금지, 구어체 트로트 과장/관용구 활용, 라인이 입에 붙음  
최소 통과: 3점

6) Album Uniqueness  
기준: 동일 훅 코어/라임 페어/메타포/댄브 구호가 이전 트랙과 중복되지 않음  
최소 통과: 3점


### [Q-GATE 1] 형태 검사 체크리스트 (Format Gate)
아래 항목 중 하나라도 실패하면 즉시 수정 루프.

1) 섹션 구성 존재 여부  
Intro / Chorus / Verse 1 / Pre / Chorus / Verse 2 / Dance Break / Bridge / Final Chorus / Outro  
이 중 하나가 누락되면 실패. 단, Interlude는 선택 사항.

2) 인트로 길이  
4마디 초과 금지. “훅 리프”가 2마디 이내 등장하지 않으면 실패.

3) 언어 규칙  
영어 문장, 영어로 된 설명형 라인, 번역된 영어 가사 혼입이 있으면 실패.  
허용: 단어 1개 구호(Hot, Hey) 또는 한글 표기(핫, 헤이).  
권장: “NO ENGLISH VOCAL” 옵션일 때는 반드시 한글 표기만 사용.

4) 훅 라인 길이  
훅은 1줄당 10~16음절 내외로 유지한다. 너무 길면 따라부르기 난이도가 올라가 실패.


### [Q-GATE 2] 기능 검사 체크리스트 (Function Gate)
1) 코러스 엔진  
코러스는 최소 2회 반복. 파이널 코러스는 “더블 훅” 또는 “훅+구호 겹치기”로 스케일업.

2) 리듬 엔진  
킥은 4온더플로어 유지. 스네어/클랩은 2&4 명확. 16분 하이햇 롤과 오픈 오프비트로 속도감.

3) 콜 앤 리스폰스  
코러스 훅에서 최소 2회, Verse에서 최소 2회 “보컬-구호/악기 답가” 구조가 있어야 한다.

4) 댄스 브레이크 목적성  
댄스 브레이크는 “가사 전달”이 아니라 “퍼포먼스 지시+구호+리듬”이어야 한다. 서사형 문장 금지.

5) 엔딩  
마지막은 페이드가 아니라 “라스트 히트(딱)” 또는 “급정지형 종지”를 기본값으로 한다.


### [Q-GATE 3] 중독성 검사 체크리스트 (Addiction Gate)
1) 반복률(코러스)  
코러스 4줄 중 2줄 이상이 동일 구조의 반복이어야 한다.  
권장 구조: A A B B 또는 A A A B.

2) 동사 반복(트로트식)  
코러스 또는 브릿지에 최소 2회 동사 반복 패턴을 넣는다.  
예: X한다 X해, X난다 X나, X진다 X져, X는다 X아.

3) 라임(Verse)  
Verse 1에서 끝소리 라임 페어 최소 2쌍. Verse 2에서도 최소 1쌍.  
라임은 “의미가 억지”가 되면 실패. 의미 자연스러움과 동시에 성립해야 한다.

4) 자음 타격(Consonant Percussion)  
강박(1,2,3,4) 또는 2&4에 오는 단어는 ㅂ/ㄷ/ㄱ/ㅆ/ㅈ 계열을 우선 배치한다.  
예: 확, 딱, 박, 쿵, 탁, 쫙, 꽉, 빡, 불, 번, 딱지, 박히다.

5) 발음 난이도  
혀 꼬이는 장문, 외래어 연쇄, 추상어 연쇄는 금지.  
한 줄에 2개 이상의 어려운 고유명사/영어/한자어 조합이 들어가면 실패.


### [Q-GATE 4] 다양성 검사 체크리스트 (Variation Gate)
앨범 누적 로그를 참조해서 중복을 방지한다. 아래 중복은 즉시 수정.

1) 훅 코어 중복 금지  
같은 2~3음절 반복 훅 코어는 앨범에서 1회만 사용.

2) 메타포 중복 제한  
불/열 계열 메타포는 앨범 10곡 기준 최대 4곡까지.  
나머지는 네온/전기/자석/술/스포츠 등으로 분산.

3) 라임 페어 재사용 금지  
동일 라임 페어는 앨범에서 재사용하지 않는다.

4) 댄브 구호 템플릿 중복 금지  
“오른쪽 왼쪽 한 바퀴” 같은 패턴은 1회만. 이후는 “점프/손뼉/짝짝/앞뒤/둘둘” 등으로 새로 설계.

5) 브릿지 선언문 구조 변주  
브릿지는 항상 “짧은 단어 + 큰 선언”이되, 문장 뼈대는 트랙마다 바꾼다.  
예: “X도 좋아 Y도 좋아”를 반복하면 2곡까지만 허용, 이후는 다른 뼈대 사용.

## [R] Revision Protocol: 실패 시 수정 루프

### [R-LAW 0] 수정은 한 번에 하나의 실패 원인만 고친다
여러 요소를 동시에 고치면 정체성이 붕괴하거나 새 실패가 생긴다.
수정 순서는 아래 우선순위를 따른다.

1) 언어 규칙 위반(영어 문장, 번역 가사 혼입)  
2) 인트로 과장(훅 2마디 내 미등장, 인트로 4마디 초과)  
3) 트로트 표식 부족(5개 미만)  
4) 훅 반복률 부족  
5) 찰짐 지표 부족(동사 반복, 자음 타격, 라임)  
6) 앨범 중복 문제(훅/라임/메타포)

### [R-STEP] 수정 액션 레시피 (원인별 처방)
1) 영어 번역 가사 혼입  
가사에서 영어 문장을 모두 제거하고, 구호는 한글 표기(핫, 헤이)로 대체한다.  
장르 프롬프트에도 “Korean lyrics only, do not translate, no English sentences”를 명시한다.

2) EDM 드리프트  
팔뮤트 기타 궁짝, 신스-브라스 콜앤리스폰스, 트로트 셔플 오버레이를 명시적으로 강화한다.  
리드 신스는 “짧은 리프트”만 허용하고 멜로디 주역에서 배제한다.

3) 인트로 과장  
Intro를 2~4마디로 줄이고, 1~2마디에 훅 리프를 바로 던진다.  
빌드업(필터 스윕, 스네어 롤)은 Pre-Chorus로 이관한다.

4) 훅이 덜 캐치함  
훅 코어를 2음절 반복으로 단순화한다.  
코러스 4줄 중 2줄은 완전 동일 문장으로 고정한다.

5) 찰짐 부족  
동사 반복 2회 추가, 자음 타격 단어를 2&4 위치에 재배치, Verse 라임 페어 1쌍 추가.

6) 앨범 중복  
훅 코어 교체가 1순위.  
훅 코어 유지가 필요하면 메타포와 라임 페어를 전면 교체하고, 댄브 구호를 완전히 다른 세트로 교체한다.

## [L] Logging & Anti-Clone: 앨범 단위 중복 방지 운영

### [L-LAW 0] 앨범 로그는 반드시 유지한다
각 트랙 생성 후 아래 항목을 로그로 저장한다. 다음 트랙 생성 시 로그를 조회해 중복을 차단한다.

1) Track ID  
2) BPM / Key  
3) Hook Core (2~3음절 반복 코어)  
4) Hook Sentence Skeleton (A-A-B-B 형태의 뼈대)  
5) Verse 1 라임 페어 2쌍, Verse 2 라임 페어 1쌍  
6) 메타포 카테고리(불/열/네온/전기/술/스포츠/기타)  
7) 댄스 브레이크 구호 세트(문장 목록)  
8) 트로트 표식 체크(몇 개 충족했는지)  
9) QA 점수표(6축 점수)

### [L-LAW 1] Anti-Clone 강제 규칙
1) 동일 훅 코어 재사용 금지(앨범 내 1회)  
2) 동일 코러스 라인(문장) 재사용 금지(앨범 내 1회)  
3) 동일 라임 페어 재사용 금지

## [Q-GATE 5] 앨범 완성도 검사 (Album Completion Gate) — 신규

아래 조건을 모두 만족해야 앨범 완료로 판정한다.

1) 완료율
- 계획된 전체 트랙 수와 `TRACKLOG_COLLECTION`의 `qa_pass`/`locked` 트랙 수가 일치해야 한다.

2) 분산성
- Key 동일 반복: 최대 2회
- 인접 트랙 BPM 차이: 0~6 허용, 권장 1~4
- MetaphorDomain 인접 중복 금지

3) 비클론성
- HookToken 중복 0
- 메인 VerbPair 중복 0
- 코러스 문장 완전 일치 0

4) 앨범 흐름
- Opener는 0:12 전후 코러스 진입이 명확해야 한다.
- Finale는 hard last hit 종결이 명확해야 한다.

5) 문서 무결성
- ALBUM_STATE / TRACKLOG_COLLECTION / Album QA Summary가 동일한 트랙 상태를 가리켜야 한다.

통과 판정:
- 조건 1~5 전부 충족 시 `ALBUM PASS`
- 하나라도 미충족 시 `ALBUM FAIL` 및 수정 루프
